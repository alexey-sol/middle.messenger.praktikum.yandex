# middle.messenger.praktikum.yandex

Мессенджер. Стек: TypeScript, Handlebars, Vite.

## Инструкция по установке

1) Склонировать репозиторий
2) Установить зависимости: `npm install`
3) Запустить для локальной разработки: `npm run dev`

## Требования и демо

- Макет (дизайн по умолчанию): https://www.figma.com/design/jF5fFFzgGOxQeB4CmKWTiE/Chat_external_link?node-id=0-1
- Демо: https://jade-mooncake-3cd203.netlify.app/

Страницы:
- `/src/chat/views/pages/chat` (или рут, без пути) - мессенджер
- `/src/profile/views/pages/profile-main` - профиль
- `/src/profile/views/pages/profile-edit` - изменение профиля
- `/src/profile/views/pages/password-edit` - изменение пароля
- `/src/auth/views/pages/sign-in` - логин
- `/src/error/views/pages/404` - ошибка 404
- `/src/error/views/pages/500` - ошибка 500

## Реализация - спринт 1

- Возникли сложности с автоматической регистрацией Handlebar паршалов (в Vite конфиге). Как выяснилось, выбранный мной плагин `vite-plugin-handlebars` не поддерживает импорт в JS модулях `*.hbs` файлов, поэтому пришлось импортировать их строками (`*.hbs?raw`) - а при таком импорте автозарегистрированные паршалы не подхватываются. Пришлось регистрировать паршалы вручную в JS модулях (за исключением общего лейаута).  
Такой проблемы нет в плагине `@yoichiro/vite-plugin-handlebars` (он умеет импортировать `*.hbs`), но у него есть другое ограничение: при авторегистрации он принимает только одну директорию с паршалами. Поскольку я храню паршалы в разных директориях, их все равно пришлось бы регистрировать вручную в таком случае. Притом этот плагин не обновлялся уже давно и не поддерживает последние версии Node.js.
- Не нашел адекватного способа подключить CSS модули в Handlebars. По всей видимости, такого способа и нет, поэтому использовал обычный "глобальный" CSS.
- Приложение сейчас работает в многостраничном `mpa` режиме.

## Скрипты

### `npm start`

Собрать статику приложения и запустить на локальном сервере.

### `npm run dev`

Запустить приложение на локальном dev-сервере (режим разработки).

### `npm run build`

Собрать статику приложения.

### `npm run preview`

Запустить собранную статику на локальном сервере.

### `npm run lint:css`
### `npm run lint:css:fix`

Команды для линтинга CSS.

### `npm run lint:js`
### `npm run lint:js:fix`

Команды для линтинга JS.

### `npm run lint`
### `npm run lint:fix`

Проверка типизации, линтинг CSS и JS.
