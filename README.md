## Скрипты

### `npm start`

Запустить приложение на локальном dev-сервере.

### `npm run build`

Собрать статику приложения.

### `npm run preview`

Запустить собранную статику на локальном dev-сервере.

### `npm run lint`
### `npm run lint:fix`

Команды eslint.

### `npm run stylelint`
### `npm run stylelint:fix`

Команды stylelint.
